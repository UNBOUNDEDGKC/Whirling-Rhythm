# Whirling-Rhythm
Made a rhythm game in swift

How to install & open on macOS
-----
Download the very cool .zip from the latest release (Shown on right side of screen).
Double-click the .zip file to extract it, then drag your new .app to your Applications folder.
The first time you open it, macOS will block it because I low key didn't wanna pay 99$/y just to put stuff on the App Store.
Open System Settings > Privacy & Security, scroll down, and click Open Anyway.
